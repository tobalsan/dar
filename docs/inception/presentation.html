Dar

A folder that works your Linear issues on its own.

Drop one small program into a project folder. Run it, and it autonomously works through your Linear issues using AI coding agents — with a live dashboard to watch and control it.

A self-contained AI work runner. One binary. One folder. No platform required.

The shift

From a big platform to a tiny program you own.

Today this capability lives buried inside AIHub, our large centralized platform. We're extracting it into its own tiny standalone program. You cd into any project folder that has a WORKFLOW.md and type dar run. That folder becomes the agent — move the folder, move the agent. Nothing else to install except the AI tool it drives.

What exists when it's done

Six things the finished product does.

1

Watches Linear

Continuously checks your Linear project for issues that are ready to work — respecting Linear's limits, never hammering it.

2

Dispatches AI agents

For each ready issue it spins up an AI coding agent (Claude, Codex, Pi, or your own) in its own isolated workspace, with a prompt you control.

3

Drives the real workflow

The agent claims the issue, moves it to In Progress, does the work, opens a pull request, links it back, and moves it to In Review — all in plain-language instructions, not hardcoded.

4

Self-heals & stays safe

Built-in retries, stall detection, and timeouts. If an agent gets stuck, it parks the issue as “Needs Human,” comments on Linear, and notifies you — never silently fails.

5

Live dashboard

A clean local web page shows active runs, history, per-run logs, the resolved workflow, and live status. Interrupt or kill any run with a click.

6

Remembers everything

Every run, event, and log is saved locally. Kill the program and restart — it picks up cleanly from the truth in Linear.
